# 摩卡貓的收納挑戰 — 設計文件

**日期**：2026-09-06
**狀態**：已實作
**同系列**：[找找看](./2026-09-01-baokaka-adventure-design.md)、[勇者團](./2026-09-06-baokaka-quest-design.md)

## 1. 目標

遊戲選單的第三個遊戲：一個**圖案數獨**。主題是摩卡貓把寶咖咖的玩具櫃弄亂了，每一橫列、每一直行、每一區都要剛好各有一個玩具，才算收好。

成功標準：一個沒玩過數獨的小孩能自己完成 4×4；會玩數獨的大人打開 9×9 不覺得幼稚，而且每一題都不需要猜。

### 非目標

- 沒有題庫檔案：題目現場產生，出不完
- 沒有計分排行、沒有每日一題、沒有多人
- 不做「殺手數獨」等變體

## 2. 玩法

三種櫃子：小櫃子 4×4（2×2 區）、中櫃子 6×6（2 列 × 3 行的區）、大櫃子 9×9（3×3 區）。**圖案／數字可切換**：圖案模式用九個既有的玩具 sprite（皮球、奶瓶、餅乾、小船、襪子、娃娃、香蕉、貝殼、蘋果），數字模式就是一般數獨；小孩看圖，大人看數字，題目是同一題。

操作只有點按：
- 先點格子再點玩具，就放進去；再點一次同樣的玩具，就拿起來
- 先點玩具再點格子，可以連續放（玩具會亮起，「放下」取消）
- 筆記模式把玩具當鉛筆記號寫在角落；放進真正的玩具時，同一橫列、直行、區裡的同款記號自動擦掉
- 選到的格子與它的同列同行同區會淡淡上色，同款玩具全部亮起，放下去會不會撞到一眼看得出來
- 放錯造成重複時，兩格都變紅，摩卡貓說「哎呀，這附近已經有一個奶瓶了」；不扣分、不擋你

**提示會教。** 按「提示」時：
1. 如果盤面上有放錯的（跟答案不同），先把它拿起來：「這一格放錯了，先拿起來，再想想看」
2. 否則找一個**唯一候選**（naked single）：「這一格只剩皮球能放：其他的在同一橫列、直行或區裡都出現過了」
3. 再否則找一個**唯一位置**（hidden single）：「這一橫列裡，皮球只剩這一格能放」

因為題目保證只用這兩種推理就能解完（見 §3），提示永遠找得到可以解釋的一步，玩家從提示裡學會的就是解題本身。

完成一列／一行／一區時那些格子閃一下綠色，摩卡貓歡呼；全部收好時整個盤面閃、播放升級音、出現星星：沒用提示 3 顆、用 1～2 次 2 顆、更多 1 顆。每種櫃子記錄收好次數、最快時間、累積星星。

## 3. 出題

`generatePuzzle(size, seed)` 純函式，同一個種子永遠出同一題：

1. 用 MRV（先填候選最少的格子）回溯，配合種子打亂的候選順序，填出一個完整合法盤面
2. 依打亂的順序一格一格試著挖空：挖掉之後若 **只靠 naked single 與 hidden single** 還能解回全盤，就保留這個洞，否則放回去
3. 挖到剩下 `MIN_GIVENS`（4×4：5、6×6：12、9×9：32）就停

只用單數推理就能解完，同時保證了唯一解與不用猜。少幾個提示只會讓題目變長，不會變難，所以 9×9 停在 32 個提示是為了「一趟捷運坐得完」。實測 9×9 一題平均不到 3 毫秒，在按下按鈕的當下產生，不需要 Web Worker。

## 4. 架構

```
src/shared/random.ts          # roll / rng / shuffle：與勇者團共用的 mulberry32
src/sudoku/
  SudokuGame.tsx              # useReducer + 存檔 effect；start 時在事件裡出題，reducer 保持純
  engine/
    types.ts                  # Size / Cells / Puzzle / Hint / Play / Stats
    grid.ts                   # 三種尺寸的區、單位、peers（每種尺寸算一次快取）
    solve.ts                  # 候選遮罩、單數解法、回溯填盤、衝突、完成的單位、findHint
    generate.ts               # 出題：填滿再挖洞
    symbols.ts                # 九個玩具、尺寸名稱、單位名稱
    sudoku.ts                 # 狀態機：選格、放、擦、筆記、提示、重來、計時、統計
    save.ts                   # localStorage key 'baokaka.sudoku'
  components/Symbol.tsx       # 圖案或數字
  components/Board.tsx        # 盤面：粗細框線、上色、筆記
  screens/SudokuTitleScreen.tsx  # 選櫃子、繼續上次的、圖案／數字切換
  screens/PuzzleScreen.tsx    # 盤面、摩卡貓對話框、玩具列、提示／筆記／重來／換一題
```

盤面一律是 `number[]`（0 = 空，1..n = 玩具），候選用位元遮罩。引擎完全不知道圖案存在；圖案只是 `Symbol` 元件的一種顯示。

存檔內容：三種尺寸的統計、顯示模式、聲音，以及**進行中的那一題**（題目、答案、玩家填的、筆記、用時、提示次數）。選取狀態、對話框、閃爍屬於當下，不存；已解完的題不會被恢復。統計在解完的那一步立刻寫入，關掉分頁也算數。

## 5. 畫面

- **選單**：三張櫃子卡片各顯示「收好 N 次 · 最快 m:ss · ★ 星星」；有進行中的題目時最上面多一顆「繼續上次的（中櫃子 · 1:23）」；「顯示：圖案／數字」切換；回遊戲選單。
- **盤面**：標題與聲音開關、用時與提示次數、正方形盤面（區與區之間 3px 粗線）、摩卡貓與對話框（沒事時每 20 秒換一句操作提示）、玩具列（右上角小數字是還剩幾個要放，放完的變淡）、清除／放下、提示／筆記／重來、換一題／回選單。重來與換一題都要再按一次確定。
- **完成**：星星、用時、提示次數、再來一題（同尺寸新題）／回選單。盤面留在畫面上。

## 6. 測試

`sudoku.test.ts`（21）：6×6 的區形狀與 peers 數、每格恰屬一列一行一區；出題決定性、三種尺寸各 12 個種子都無衝突且單數可解回答案、提示數不低於下限；衝突偵測、完成單位、提示先抓錯再給步驟且能一路提示到解完；狀態機的放／拿／畫／筆記與 peers 清除／提示計次／解完記統計且只記一次／中途離開可續、重來歸零／星星規則；存檔往返去掉暫態、不恢復已解完的題、壞資料退回預設。
