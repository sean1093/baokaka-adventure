# 全站視覺改版 — 設計系統

**日期**：2026-09-06
**狀態**：已實作
**範圍**：遊戲選單、找找看、勇者團、收納挑戰的所有畫面

## 1. 為什麼改

第一版的視覺語言是「4px 深色描邊 + 硬陰影的卡通方塊」，三個遊戲各自長出自己的字級與按鈕，畫面愈多愈亂：標題頁、地圖、戰鬥面板、數獨盤面沒有共同的階層，重要按鈕與次要按鈕一樣大，確認對話夾在版面裡。這次改版把整站收斂成一套 token 與六個元件，畫面只負責組合。

## 2. Token（`tailwind.config.js`）

- **字級**：`caption` 13 / `label` 15 / `copy` 17 / `heading` 20 / `headline` 24 / `display` 32 / `hero` 40。找找看維持長輩下限，只用 `heading` 以上。
- **顏色**：`palette.ts` 的角色色票原封照搬（sprite 與 UI 永遠同一組色），另加三個純 UI 中性色：`bg`（頁面）、`surface`（卡片）、`muted`（次要文字）。
- **圓角**：`2xl` 16 / `3xl` 24 / `4xl` 32。**陰影**：`card`（浮起的面）、`float`（底部面板）、`glow`（主要按鈕的暖光）、`inset`。
- **背景**：`body::before` 三個徑向漸層（左上白光、右下暖光、左下天空藍），所有卡片都浮在同一片光上。

## 3. 元件（`src/components/`）

| 元件 | 用途 | 規則 |
|---|---|---|
| `Screen` | 每個畫面的外框 | 手機寬、safe-area、掛載時 `screen-in` 上滑；`center` 給標題與結果頁，`fixed` 給鎖定視窗高的戰鬥與尋物場景 |
| `AppBar` | 頂欄 | 左圓形返回鍵、兩行標題（kicker + title）、右側放 `SoundToggle` 等；取代所有自製 header 與大顆「回選單」按鈕 |
| `Button` | 唯一的按鈕 | 膠囊形；`primary`（每個畫面最多一顆，暖漸層 + glow）、`tonal`、`ghost`、`danger`；`xl` 是找找看的 64px 下限 |
| `IconButton` | 圓形圖示鍵 | `label` 必填；`active` 反白 |
| `Card` / `Chip` | 面與標籤 | `surface`（有影）、`tonal`（無影）、`accent`（暖漸層）；Chip 六個色調 |
| `Sheet` | 底部面板 | 所有不可逆選擇（重來、換一題、重新開始、放棄）都走這裡：問一句 + 兩顆按鈕，背景模糊；portal 到 body |
| `icons.tsx` | 24px 線條圖示 | `currentColor`，沒有 icon font、沒有 emoji |

## 4. 畫面規則

1. 一個畫面只有一個 primary；其他動作降為 tonal / ghost，或收進 AppBar。
2. 選取與啟用狀態用色塊與 `ring-2`，不用粗邊框。分隔線是髮絲線。
3. 可點元素 ≥ 44px（找找看 ≥ 64px）；`text-muted` 是最淡的正文色，對比 ≥ 4.5:1。
4. 動效只有四種：畫面進場、面板上滑、`pop` 回饋、按鈕按下縮放；`prefers-reduced-motion` 時關掉裝飾動畫。
5. Sprite 與場景（尋物場景、戰鬥方塊、橫向地圖）一律不動，只換它們周圍的框、字與按鈕。

## 5. 各遊戲的落點

- **選單**：漸層 hero + 三張漸層磁磚（種類 Chip、標題、一句話、進度 Chip、黑色「開始」膠囊）。
- **找找看**：標題卡、進度條 + 六張關卡卡（完成打勾 Chip、未開鎖頭），場景框去邊加影，托盤三格改成淡底／白底 + 綠勾。字級全部 ≥ 20px，按鈕 64px。
- **勇者團**：標題頁的「繼續冒險」變成一張帶播放鍵的存檔卡；地圖上「往左／往右」是兩顆 64px 膠囊（右邊為主）；戰鬥面板用淡色格子（花元氣的招式帶暖底）、道具收進右上角的 tonal 按鈕、目標選取用 ring；勝利／營地／故事全部改成單卡 + 一顆主按鈕。
- **收納挑戰**：三張櫃子卡（色底尺寸章、統計 Chip）、圖案／數字 segmented control；盤面髮絲線 + 2px 區線、選取橘、同款藍、衝突紅；玩具托盤白底圓格 + 黑色計數章；提示是唯一的 primary，重來／換一題走 Sheet。

## 6. 驗證

144 個測試不動（純視覺改版）；三個遊戲的每個畫面在 390×844 與 375×667 各截圖一次確認不溢出、不重疊；`tsc -b` 與 `vite build` 通過，CSS gzip 5.9 KB。
