## A. 真機測試（約 1～1.5 小時）

需要兩支手機：**一支 2021 年左右的中階 Android**（例如 Samsung A52、Pixel 5a 等級），**一支 iPhone**。每支手機都從**全新存檔**開始（第一次打開，或 設定 →「重新開始」按住 3 秒）。

### A1. 第一次打開（兩支都做）

| | 項目 | Android | iPhone |
|---|---|---|---|
| 1 | 4G（關掉 Wi-Fi）打開網址：封面 **3 秒內**出現，按「開始」後第一頁 **3 秒內**可以玩 | ☐ | ☐ |
| 2 | 封面只有「開始」一個按鈕（全新存檔時這是正常的）；按下去有聲音（iPhone 側邊靜音開關要打開成有聲） | ☐ | ☐ |
| 3 | 字都清楚、沒有方框（缺字）或變成系統字體 | ☐ | ☐ |
| 4 | 玩完 0-1 後回封面：出現「繼續」、「目錄」、「相簿」、「設定」，按「繼續」**一下**就回到剛剛那頁 | ☐ | ☐ |

### A2. 流暢度（最重要）

每章最重的那頁各開一次（網址後面加 `#/?page=頁碼`，例如 `…/baokaka-adventure/#/?page=c8p6`）。玩 30 秒，看會不會卡頓、掉格。

清單是 `scripts/perf-check.mjs` 的 `PERF_PAGES`（每章最慢和最忙的頁；工程師用 `check:perf` 在電腦上、CPU 放慢 4 倍量到 55 fps 以上；真手機有 GPU，應該更好）。時間不夠的話，每章挑一頁（粗體）：
**`c0p3`** `c0p1` · **`c1p6`** `c1p3` · **`c2p6`** `c2p3` · **`c3p3`** `c3p1` · **`c4p6`** `c4p5` · **`c5p2`** `c5p1` · **`c6p4`** `c6p2` · **`c7p6`** `c7p2` · **`c8p6`** `c8p5` · **`c9p2`** `c9p4` · **`c10p6`** `c10p1` `c10p2` · **`c11p1`**（尾聲）· **`c12p1`**（番外）

| | 項目 | Android | iPhone |
|---|---|---|---|
| 5 | 以上每頁都順，拖拉紙片時跟得上手指 | ☐ | ☐ |
| 6 | **省電模式**（慢手機上）：畫面連續 2 秒太慢時會自動變簡單（少一點動畫）；順了 10 秒會恢復一次，第二次就一直保持簡單。只要不卡、不閃就算過 | ☐ | — |
| 7 | 玩 15 分鐘手機不會燙到不舒服、電量掉得合理 | ☐ | ☐ |

### A3. 手機功能

| | 項目 | Android | iPhone |
|---|---|---|---|
| 8 | **震動**（設定 → 震動 開）：拖到定位、摩卡推東西、拿到貼紙時會輕輕震一下 | ☐ | 不適用（iPhone 的瀏覽器不支援） |
| 9 | **書本傾斜**（設定 → 書本傾斜 開）：iPhone 會先問「允許動作感應」，允許後手機左右傾，書的各層會跟著微微錯開；不會暈 | ☐ | ☐ |
| 10 | **加到主畫面**（分享 →「加入主畫面」）後從圖示打開：上方的標題列在瀏海／狀態列**下面**、下方的按鈕在 Home 橫條**上面**，都按得到 | ☐ | ☐ |
| 11 | **轉橫**：玩到一半把手機轉橫，畫面出現「請把手機轉直，再繼續玩喔」；轉回直的，從剛剛的地方繼續 | ☐ | ☐ |
| 12 | **靜音玩一章**（音量關到 0 或靜音）：所有提示和劇情還是看得懂（字幕、動作都在） | ☐ | ☐ |
| 13 | 切到別的 App 再回來、或鎖螢幕再打開：遊戲還在原來那頁 | ☐ | ☐ |
| 14 | 斷網（飛航模式）後繼續玩**已經打開的這一章**：可以玩。換到還沒載入的下一章會需要網路（遊戲沒有離線快取，這是已知的） | ☐ | ☐ |

### A4. 設定（在其中一支做就好）

| | 項目 | ☑ |
|---|---|---|
| 15 | **長輩模式**：開了以後 速度＝慢、字＝大字、自動提示更快，都鎖住；畫面上的字明顯變大，沒有字被切掉 | ☐ |
| 16 | 長輩模式下，小螢幕手機上的相簿頁：家人的留言卡如果一次看不到全部，可以往下滑看到 | ☐ |
| 17 | **左手模式**：下面的按鈕列左右對調，說話的字圈也從另一邊出來 | ☐ |
| 18 | **減少動態**：翻頁、卡片都變成淡入淡出，沒有東西閃爍 | ☐ |
| 19 | 音效、音樂音量調整有作用；「重新開始」要按住 3 秒才會清除進度 | ☐ |
| 20 | 以前玩過舊版 RPG 的手機打開：封面有「寶咖咖的新冒險開始了！」的卡片，新遊戲正常開始 | ☐ |

## B. 家庭試玩（一個週末，輕鬆玩）

目的是 GDD §8 的三個「上線訊號」，加上看工程師留下的觀察點。不需要像 M1 那樣一位一位計時，大家一起玩就好；有空的話用 `#/?debug=metrics` 網址留紀錄。

### B1. 上線訊號（GDD §8）

| | 訊號 | 有／沒有 | 備註 |
|---|---|---|---|
| 1 | 全家**一起坐在沙發上**玩（有人湊過來看、指、搶手機） | ☐ | |
| 2 | **阿嬤隔天自己問要再玩** | ☐ | |
| 3 | 有人把**相簿**拿給親戚看 | ☐ | |

### B2. 請特別留意（工程師留下的觀察點）

AI 自動玩過全部 65 頁＋番外（[`ai-playtest.md`](ai-playtest.md)），以下是「猜測修好了，但要真人確認」的地方：

| | 頁 | 看什麼 | 順／卡住 |
|---|---|---|---|
| 1 | 7-5、8-5、9-4（轉盤控制高低：茶壺、水龍頭、日晷） | 看得出轉盤要往哪個方向轉、轉到哪一格嗎？ | ☐ |
| 2 | 10-4（阻尼球） | 知道要讓摩卡坐上去，球才會擺過去嗎？地上印的路線有幫助嗎？ | ☐ |
| 3 | 10-3（101 的八節） | 看得懂哪一節被摩卡壓住、哪一節可以轉嗎？ | ☐ |
| 4 | 有「說話」的頁（例如 4-1、9-6） | 「提示」說「試試看說『○○』」時，知道要點寶咖咖或「說話」嗎？ | ☐ |
| 5 | 每頁結束的貼紙卡 | 翻頁時手指剛好點下去，會不會誤點到下一頁？ | ☐ |
| 6 | 4-1、4-5、4-6、5-1、7-1、8-1、3-4 | 一直按「提示」能不能順利過關？（這次修好了一個會一直重複同一步的問題，要真人確認） | ☐ |
| 7 | 整體 | 哪一頁最好玩？哪一頁最久？有沒有人卡超過 2 分鐘又不想按提示？ | |

### B3. 結果怎麼交

1. 每一項的結果、家人說的話（只寫角色：阿嬤、小孩、爸爸、媽媽，不寫名字），寫進 [`beta-results.md`](beta-results.md)，或直接留言在 #138 由工程師整理。
2. 有開紀錄的話：紀錄面板按「複製 Copy」，貼上。
3. 要修的地方，工程師會開 issue、修好、再請你看一次。
