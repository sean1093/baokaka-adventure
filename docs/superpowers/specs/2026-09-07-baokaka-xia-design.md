# 寶咖咖奇俠傳 — 設計文件

**日期**：2026-09-07
**狀態**：已實作
**取代**：`2026-09-06-baokaka-quest-design.md`（回合制勇者團，橫向捲軸版）

## 1. 為什麼重做

前一版「勇者團」是一條線：走橫向捲軸的路 → 撞到敵人 → 打完 → 下一站。地圖只有前後，NPC 不存在，戰鬥只有「技能／道具／防禦」三顆按鈕。玩兩章就知道剩下四章長什麼樣。

這一版按使用者要求，改成**仙劍奇俠傳式的體驗**：

| 仙劍的要素 | 這裡怎麼做 |
|---|---|
| 斜角俯視的城鎮與野外，用走的探索 | 2:1 等距地圖（`iso.ts`），點地板 BFS 走過去 |
| 跟每個人講話，話會隨劇情變 | `Npc.talk` 規則列表，第一條符合旗標的生效 |
| 寶箱、店家、客棧 | 玩具箱、貼紙商店、豆花阿伯的午睡 |
| 隊伍會長大，成員各有仙術 | 寶咖咖 → 摩卡貓 → 小鴨鴨，各 4 招 |
| 指令式戰鬥：攻擊／仙術／物品／防禦／逃跑 | 一模一樣的五個指令，加上「接下來輪到誰」 |
| 身法決定出手順序 | `spd` 排序，同速玩家先動 |
| 隨機遇敵 | 每張地圖有危險區與遇敵率，走路時判定 |
| 章回體、過場對白、片尾 | 章名卡、逐字打出的對話框、結局頁 |

## 2. 玩法

### 探索
點地板 → 隊伍走過去（BFS 找路，四方向）。點 NPC 或玩具箱 → 走到旁邊再互動。摩卡貓和小鴨鴨跟在後面，重走隊長走過的格子。相機跟著隊長，但夾在地圖邊界內，不會把空白拉進畫面；擋住主角的高物件（樹、遮陽傘）自動變半透明。

### 戰鬥
一到三隻敵人。所有人依 `spd` 排序輪流出手：

- **攻擊**：`atk - 敵防/2`，浮動 ±10%，暴擊機率 `5% + 幸運%`，傷害 ×1.5
- **仙術**：花真氣。傷害系威力 = `(atk×0.7 + 等級×2) × power`；治療系是目標最大體力的比例
- **道具**：補體力、補真氣、全滿、復活
- **防禦**：這一輪受到的傷害減半，並回 4 點真氣（唯一的真氣來源，所以是真的取捨）
- **逃跑**：`55% + (我方平均身法 - 敵方最高身法)×3%`，夾在 25%～90%；頭目戰不能逃

敵人的下一招會顯示在畫面中央，所以「要不要防禦」是有資訊的決定。

### 死亡
沒有懲罰：回到那張地圖的入口，全隊 40% 體力，道具、貼紙、經驗全部保留。

## 3. 內容

七張地圖 = 七章：客廳 → 院子 → 公園 → 市場 → 浴缸島 → 海邊 → 棉被山。
劇情主線：安撫娃娃被打呼嚕大王抱走了；一路上摩卡貓、小鴨鴨加入，五個頭目擋路。

- **18 個搗蛋鬼**（沿用前作的 sprite），其中 5 個頭目
- **13 種道具**：6 種消耗品 + 7 種裝備（每人一格）
- **11 招仙術**，等級 1～8 陸續學會
- **等級上限 12**，經驗表 `XP_TABLE`
- **貼紙**是貨幣：打敵人拿、劇情給，用來買東西和睡客棧

## 4. 檔案

```
src/quest/
  engine/
    types.ts      資料契約（全部是純資料）
    iso.ts        2:1 投影、地形樣式
    path.ts       BFS 找路、可走判定、劇情條件
    maps.ts       七張地圖（格線用文字畫）
    events.ts     所有台詞與過場
    heroes.ts     三個角色、仙術、道具
    foes.ts       18 個敵人
    battle.ts     戰鬥引擎（純函式）
    scene.ts      劇本執行器
    quest.ts      整場遊戲的 reducer
    save.ts       存檔讀寫與驗證
    validate.ts   內容檢查（開發時啟動就跑）
    sim.ts        無頭平衡模擬
  components/     IsoMap、對話框、章名卡、隊伍面板
  screens/        World / Battle / Shop / Victory / Defeat / Title / Ending / PartySheet
```

引擎全部是純函式，UI 不改狀態。地圖格線是字串陣列，改地圖不用動程式。

## 5. 平衡

`npm run sim [seeds]` 讓三個腳本玩家把整條主線跑幾百遍，回報每場頭目戰的敗率、回合數、等級與剩餘血量。200 seeds 的結果：

| 玩法 | 通關率 | 說明 |
|---|---|---|
| careful（會補血、會防禦、會補給） | 99% | 頭目 3～11 回合 |
| casual（血很低才補，不防禦） | 88% | 最後一關 9% 敗率 |
| reckless（只會攻擊） | 38% | 第 3、4 章就會卡住 |

`sim.test.ts` 把這三條線釘成測試：內容一改壞，CI 就會抓到。頭目不再有回血招式——一旦玩家真氣見底，會回血的頭目會讓戰鬥變成打不完的僵局。

## 6. 音樂

`shared/audio.ts` 用 WebAudio 排程五段循環（野外／夜晚／戰鬥／頭目／結局），旋律寫成五聲音階的音級序列，一次排一小節。沒有任何音檔，全站靜音也能完整通關。

## 7. 美術

新增 13 個 sprite（`art/sprites/folk.tsx`、`town.tsx`）：小鴨鴨、媽媽、爸爸、阿嬤、小花、小狗、老闆娘、阿伯、玩具箱（開／關）、路標、午睡墊、浴缸。全部遵守既有的 `art/sprite.ts` 規則（100×100 viewBox、只用 `palette.ts` 的顏色、`C.ink` 描邊）。

地形是 CSS clip-path 菱形，牆和籬笆多畫兩個側面變成方塊。沒有點陣圖。

## 8. 測試

77 個 quest 測試（戰鬥 20、reducer 26、存檔 13、內容 12、平衡 6），全站 178 個。`validate.ts` 檢查：格線寬度一致、NPC 站得到、寶箱走得到、出口互通、事件都存在且都被用到、頭目有台詞、每個道具都拿得到。
